# Learning guide

New to software? This guide teaches the ideas and tools you need to work on the rover's
code, from opening a terminal for the first time to sending your first change to the team.
It assumes you have never programmed, used Git, or typed a command before.

## How to use this guide

Read the pages in order. Each one explains a few ideas in plain words, then gives you
something to try. Type the commands yourself instead of only reading them: doing it is
what makes it stick. Nothing in the exercises can break your computer or the robot.

When you meet a word you do not know, look it up in the [glossary](glossary.md).

## The path

1. **[The command line](command-line.md):** what a terminal is, and how to move around
   your files and run commands by typing.
2. **[Git and GitHub](git-and-github.md):** how the team keeps track of every change to
   the code and reviews changes before they reach the robot.
3. **[Containers and the dev container](containers.md):** what Docker does, and how the
   files on your computer show up inside a container.
4. **[Getting started](../getting-started.md):** set up your computer for real. This is
   where the first three pages come together.
5. **[ROS 2 basics](ros2-basics.md):** how the robot's programs talk to each other. You
   will watch messages flow and drive a simulated turtle from the command line.
6. **[Your first pull request](first-pull-request.md):** send a real change to the team,
   step by step.

Already know some of this? Skip ahead; each page lists what it covers at the top.
